A 4 KB Python chess engine for make.fun's tiny-chess-01 bounty: alpha-beta search with quiescence and piece-square tables, playing through the make.fun env protocol (`MAKEFUN_ENV_URL`). Python 3.13, standard library only, deterministic by construction.

## Run it

```sh
python3 -P -s main.py
```
